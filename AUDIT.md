# Аудит frontend-web

Проверены страницы, общие компоненты, озвучка, состояния загрузки/ошибок,
навигация, авторизация и клиентские зависимости. Незаконченные разделы
(«Разбор», профиль, часть курса) в ошибки не включались — это отдельная
незавершённая функциональность.

## Безопасность

### Критично: дамп БД с персональными данными в репозитории

`hanibo.sql` был в индексе Git и содержит пользователя с реальным email и
bcrypt-хешем пароля. Файл убран из индекса, `*.sql` добавлен в `.gitignore`.
Сам файл остался локально, но в новых коммитах его нет.

Важно: **история Git всё ещё содержит старую версию дампа**. Если репозиторий
публичный, нужно:

1. сменить пароль пользователя из дампа;
2. вычистить файл из истории (`git filter-repo --path hanibo.sql --invert-paths`
   или BFG) и сделать force-push.

Без этого удаление из текущего коммита не убирает данные из истории.

### Высокий уровень: уязвимая транзитивная зависимость

`npm audit` показывал high в `follow-redirects` (через axios). Выполнен
`npm audit fix`; сейчас `npm audit` — **0 уязвимостей**.

### Средний уровень: JWT в localStorage

Токен хранится в `localStorage` (`hanibo_token`). При XSS его можно украсть.
Правильнее — httpOnly/Secure cookie + CSRF-защита на бэкенде. Пока XSS-векторов
в коде не найдено: `dangerouslySetInnerHTML` нет, markdown рендерится через
`react-markdown` без `rehype-raw`, `innerHTML` используется только для очистки
контейнера прописей. Но CSP в `index.html` тоже нет — это следующий шаг.

### Средний уровень: dev-сервер слушает все интерфейсы

`vite.config.ts` теперь `host: "0.0.0.0"` — это нужно для доступа из Windows к
WSL. На публичном Wi-Fi dev-сервер и прокси к API будут доступны соседям по
сети. Для разработки это осознанный компромисс, для продакшена — нет.

### Низкий уровень: прогресс курса в localStorage

`wordsPercent`/`grammarPercent`/`finalPercent` хранятся на клиенте
(`utils/progress.ts`). Их можно подделать через DevTools, чтобы разблокировать
уроки. Это не денежная/привилегированная операция, но сервер не должен
доверять этим значениям, если на них появятся награды или платный контент.

## Исправленные ошибки

- **Мини-игра «Найди правило» была без стилей**: компонент использовал классы
  `grammar-mini-game__*`, а SCSS описывал `choose-rule-game__*`. Классы
  приведены к SCSS; добавлены заголовок, счёт, состояния и focus-visible.
- **Озвучка была в трёх реализациях** (`lib/speech.ts`, `lib/useSpeech.ts`,
  локальная функция в `LetterModalBlock`) и не выбирала корейский голос.
  Теперь один `speakKorean`: выбирает установленный корейский голос,
  отменяет предыдущую фразу, ограничивает rate, корректно переживает баг
  Chrome с `cancel()` + `speak()`. Все компоненты используют его, кнопки
  блокируются, если синтез речи недоступен.
- **Порог 70% был строгим (`> 70`)**: ровно 70% не проходило. Заменено на
  `>= PASS_THRESHOLD`; процент в тесте теперь округляется одинаково для
  результата и для решения «пройден/не пройден».
- **Редирект после логина**: `ProtectedRoute` передавал объект `location`, а
  `LoginPage` ждал строку. Теперь передаётся и валидируется локальный путь
  (`/...`, без `//`), это заодно закрывает open-redirect.
- **Истёкший токен** оставлял пользователя на странице с ошибками 401.
  Добавлен response-interceptor: 401 очищает токен и разлогинивает через
  событие `hanibo:auth-expired`.
- **Пустой экран при загрузке авторизации** (`return null`): заменён на
  `StateBlock`.
- **Нет подтверждения пароля при регистрации**: ошибка сервера
  `password_confirmation` не отображалась. Добавлена проверка «Пароли не
  совпадают» и поле ошибки.
- **Нет 404 и ErrorBoundary**: добавлены страница 404, корневой
  `ErrorBoundary` и fallback для lazy-загрузки.
- **Словарь/грамматика/фразы при ошибке не давали повторить запрос**:
  добавлена кнопка «Повторить» во все три сетки.
- **Магазин молчал при ошибке покупки/экипировки**: теперь действие
  показывает сообщение об ошибке, а не оставляет необработанный rejection.
- **В библиотеке не было кнопки возврата из PDF**, а у «Продолжить чтение»
  кнопка была без стилей. Добавлена ссылка назад, общий `.btn`.
- **Не было сброса фильтров** в словаре/грамматике/фразах, хотя в библиотеке
  он есть. Добавлена общая кнопка «Сбросить», которая появляется только при активных фильтрах.
- **Flashcard-таймеры** могли сработать после размонтирования; добавлена
  очистка, `onAnswer` теперь получает ответ и для флешкарт.
- **Мобильное меню** не блокировало прокрутку страницы и не закрывалось по
  Escape; исправлено.
- **Debug-мусор**: удалён `console.log` в `libraryRecent`, пустой
  `components/.gitkeep`, лишние классы без стилей.
- **`index.html`**: `lang="ru"`, нормальный title и description.
- Стили грамматики переименованы из `styles/pages/GrammarTab` в
  `styles/pages/GrammarPage` — теперь папка совпадает со страницей.

## Что проверено и в порядке

- `react-markdown` без raw HTML; пользовательский HTML не вставляется.
- Нет `eval`, `new Function`, `document.write`, `window.open` с внешними URL.
- PDF-рендер и миниатюры обрабатывают отмену рендера и не роняют страницу.
- API-клиент имеет таймаут 10 секунд; ошибки страниц обрабатываются.
- Формы имеют `autoComplete`, `aria-invalid`, `role="alert"` у общих ошибок.
- Мобильные тач-цели, safe-area и `prefers-reduced-motion` учтены.

## Что осталось (не ошибки, а незавершённые разделы)

- «Разбор» — заглушка;
- профиль — отсутствует;
- часть курса — не готова;
- вид списка библиотеки: тип и измерение полок есть, переключателя в UI нет;
- полноценный focus-trap для всех модалок (сейчас закрытие по Escape, блокировка
  скролла и возврат фокуса есть не везде);
- CSP и httpOnly-cookie для токена — требуют настройки бэкенда.
